## Getting Started

### Prerequisites
- [MongoDB Engine](https://www.mongodb.com/try/download/community)

### Installation
1. Start Docker Engine.
2. Clone the repository:
   ```sh
   git clone https://gitlab.duthu.net/S52100086/project_nodejs.git
3. Navigate to the workspace:
   ```sh
   cd /src
4. Install dependencies:
      ```sh
   npm i
5. Start the server:
   ```sh
   npm start
6. Import the database using MongoDB Compass and import data from the /data directory.
